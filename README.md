Учебная база 1С для третьего итогового проекта на платформе Skillbox.
Доработка типовой конфигурации через расширение, внешние обработки и интеграции.

## 📋 Что реализовано в проекте:

### Задача 1. Учёт себестоимости и контроль остатков
- Новый регистр накопления «СебестоимостьТоваров» (Остатки, Измерения: Номенклатура, Склад; Ресурсы: Количество, Себестоимость).
- Доработка документов «ПоступлениеТоваров» и «РеализацияТоваровИУслуг» через расширение.
- Контроль отрицательных остатков при проведении реализации.
- Списание себестоимости по средней цене.

### Задача 2. Новый аналитический отчёт
- Внешний отчёт (.erf) «Анализ остатков и себестоимости» на СКД.
- Выводимые данные: Номенклатура, Склад, Количество, Себестоимость.
- Вычисляемое поле: «Средняя себестоимость единицы» (Себестоимость / Количество).
- Несколько вариантов настроек отчета (с группировкой по складам, по номенклатуре, таблица).

### Задача 3. Автоматическая проверка контрагентов
- Новое перечисление «СтатусыНадежности».
- Новые реквизиты справочника «Контрагенты»: МаркерНадежности, ОГРН.
- Программное добавление поля и кнопки «Обновить маркер» на форму контрагента через расширение.
- HTTP-запрос (GET) к API DataNewton для получения статуса по ОГРН.
- Парсинг JSON-ответа, анализ показателя `code_egr` и обновление маркера.
- Периодический регистр сведений «ИсторияМаркеровНадежности».

### Задача 4. Печатная форма для перемещения
- Новый документ «ПеремещениеТоваров» в основной конфигурации.
- Движения по регистру «ТоварыНаСкладах» (Расход/Приход).
- Внешняя печатная форма (.epf) по форме ТОРГ-13.
- Подключение через механизм встраиваемых обработок БСП.

### Задача 5. Настройка обмена данными
- План обмена «ОбменСФилиалом».
- Включение в состав плана справочников и документа «ПеремещениеТоваров».

### Задача 6. Создание вида расчёта зарплаты
- План видов расчёта «ДополнительныеНачисления».
- Регистр расчёта с реквизитами по аналогии с основными начислениями.
- Табличная часть «Дополнительные начисления» в документе «Начисление зарплаты».

## 📦 Как развернуть базу и файлы:
1. Скачайте файл `.dt` из раздела **Releases** (Релизы) справа на этой странице.
2. Создайте новую пустую базу в 1С и загрузите в неё файл `.dt` через Конфигуратор.
3. Дополнительные файлы (`.erf`, `.epf`, `.cfe`) находятся в папке `ExternalProcessing` или в разделе **Releases**.
